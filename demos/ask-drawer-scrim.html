Prečo po Open file zbledne ľavá strana

Nie je to fade animácia layoutu. Drawer je modálny overlay cez celý Ask desk (inbox + chat + sources). Backdrop je namiešaný z tokenu --ink, ktorý v dark mode nie je čierny — je to svetlá farba textu. Preto strana zbledne, namiesto toho aby sa slušne stmavila.

Čo sa deje dnes

Pattern A z demos/source-preview.html sa prepísal 1:1. Overlay je position: absolute; inset: 0 nad .ask-desk a má aria-modal="true" + focus trap. 

background: color-mix(in srgb, var(--ink) 28%, transparent);
  • Light: --ink je #1c1b18 → 28 % čiernej = šedý závoj, chat ostane čitateľný.
  • Dark: --ink je #eceae4 → 28 % bielej = vybielenie inboxu a odpovede.

Je to best practice?

Scrim áno — ale len pre blocking modal (uložiť / zahodiť, platba, alert). A vždy z čiernej, nie z textovej farby.

  • Material, Apple HIG, Fluent: overlay black 32–50 % v oboch témah.
  • NotebookLM, Claude, VS Code, Gmail: náhľad súboru je doplnkový panel, nie modal. Chat nesmie zblednúť — porovnávaš citát s odpoveďou.
  • WCAG: ak necháš aria-modal, pozadie má vyzerať inertné. Ak preview nie je modal, scrim je nielen zbytočný, ale aj zlý.

Esteticky: 28 % ink v dark mode je chyba tokenu. Funkčne: zhasnúť konverzáciu pri čítaní zdroja je pre RAG nesprávny pattern.
