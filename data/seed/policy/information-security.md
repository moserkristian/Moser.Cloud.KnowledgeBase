# Information security — credentials (INFOSEC-03)

Effective: 18 August 2026  
Owner: Information Security

Passwords, API keys, and service credentials are Restricted. Employees **must not share** passwords, API keys, or credentials with vendors, coworkers, or tickets.

- Use the approved secrets vault.
- Rotate a key if it was pasted into chat.
- SSO is mandatory for production consoles.

**Never share** an API key, even with a "trusted" vendor engineer. Provision a scoped, time-limited credential through Vendor Access instead.

Phishing: report to infosec@internal within one hour. Do not forward the raw message to a wide DL.
