# Data classification (SEC-DATA)

Effective: 18 August 2026  
Owner: Information Security

Labels: Public, Internal, Confidential, Restricted.

Restricted includes customer PII, payroll, and unreleased financials. **Never export customer PII** to personal email or unsanctioned SaaS. **Do not dump customer PII** into tickets or chat.

Confidential source code stays in the company Git host. Screenshots of Restricted data are prohibited in Slack.

If a vendor asks for a production data extract, open a Security review. Do not send a CSV "just this once".
